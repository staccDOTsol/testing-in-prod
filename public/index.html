this is app.burnpr.fun

burn a proof.
ship a change.

Burn one Homecoming NFT on Robinhood Chain. In return you get one prompt that changes a real product — whatever you want, however you want it. An agent does the work, opens the PR, merges it, and redeploys. Nobody reviews it. That's the whole thing.

start a burn how it works

This deploy is itself proof of the mechanic — it was shipped by burning a prompt.

how it works

  1. 01

    connect wallet

    Connect the wallet holding your Homecoming NFTs and pick which one you're willing to burn.

  2. 02

    pick a product & write the prompt

    Choose a live repo from the target list and write the one change you want made to it — up to 4000 characters.

  3. 03

    burn & submit

    The NFT is burned on Robinhood Chain. The burn transaction is the only proof of intent required — no review queue, no approval step.

  4. 04

    agent ships it

    An agent implements the change in the spirit it was asked, opens a pull request, merges it, and redeploys the product. Done.
